# 漫游默认斜向俯视机位设计

## 目标

把漫游模式现有的房间内门口初始机位改为斜向、从上往下俯视当前房间的初始机位，构图参考用户提供的截图。

## 范围

- 只替换漫游模式初始化时使用的相机位置、偏航角和俯仰角。
- 保持现有视角 effect 的触发时机不变，包括首次进入漫游模式、空间或房间变化时现有代码是否重新定位。
- 保持 WASD 飞行、升降、加速、拖动环视、家具选择和其他模式的相机行为不变。
- 不修改沉浸、平面或布局模式的初始机位。

## 方案

新增一个无副作用的漫游初始姿态计算函数。函数接收当前房间的位置、旋转和长宽，返回世界坐标中的相机位置，以及面向房间中心所需的 `yaw` 和 `pitch`。

机位在房间局部坐标中位于一个斜对角方向，高度和水平偏移按房间长宽自适应，使不同尺寸与旋转角度的房间都获得相近的斜向俯视构图。目标点位于房间中心附近，避免继续使用门口第一人称视角。

`RoomScene` 的漫游分支只消费该姿态结果并写入现有相机与 `walkRef`；不改变该分支的进入条件、清键逻辑或后续逐帧控制。

## 代码边界

- 姿态计算归属 `src/three/`，保持为可独立测试的 Three.js 领域计算。
- `RoomScene` 继续负责模式切换和把姿态应用到真实相机。
- 不在页面、状态 hook 或 HUD 中增加逻辑。

## 验证

1. 先为默认房间写失败测试，确认初始相机位于房间上方的斜对角位置，并向下朝向房间中心。
2. 为旋转房间写失败测试，确认姿态随房间旋转而旋转，而不是固定在世界坐标方向。
3. 实现最小计算逻辑使测试通过，再运行完整测试与生产构建。
4. 启动实际页面，进入漫游模式并截图检查构图是否接近参考图；界面验收与自动化结果分开报告。

## 非目标

- 不改变漫游模式何时重置视角。
- 不增加相机过渡动画。
- 不改变用户输入、移动速度、碰撞或视角旋转限制。
