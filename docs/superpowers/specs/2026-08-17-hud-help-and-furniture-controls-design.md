# HUD 操作说明与家具栏控制设计

## 目标

重新组织操作说明、全局设置、房间设置和家具设置的入口，让每个入口只承载对应范围的功能；为底部家具栏增加纯 UI 的收起与展开能力。

## 顶部操作说明

- 从全局设置弹窗中移除问号按钮、展开状态和操作说明内容。
- 在顶部模式切换栏右侧紧邻放置独立问号按钮。
- 点击问号按钮打开独立“操作说明”弹窗，展示现有布局、平面、漫游、沉浸和家具放置说明。
- 全局设置弹窗继续保留空间管理与沉浸眼高设置。

## 底部家具栏

- 删除家具栏左侧“建造”图标、文字和分隔线。
- 展开状态继续显示全部家具卡片。
- 在整个家具栏的右上角放置独立家具设置按钮。
- 增加收起按钮；点击后隐藏整个家具栏主体，底部中央只保留小型展开按钮。
- 收起与展开只改变 UI 可见状态，不取消家具选择、不退出放置状态、不改变快捷键行为，也不修改任何家具或房间数据。
- 家具栏默认展开，折叠状态不持久化。

## 家具独立设置

- 新增独立“家具设置”弹窗，由家具栏右上角设置按钮打开。
- 将房间设置中的“8 人办公方案”、购物清单、预算统计和“清空家具”整体迁移到家具设置弹窗。
- 迁移后这些操作继续作用于当前房间，计算方式、确认行为和业务回调保持不变。
- 房间设置只保留房间名称、位置、旋转、尺寸、墙角、门窗等房间结构配置。

## 组件与状态

- `OperationHelpDialog` 负责操作说明内容。
- `FurnitureSettingsDialog` 负责办公方案、清单、预算和清空家具。
- `TopBar` 增加打开操作说明的回调。
- `FurnitureBar` 管理本地展开/收起状态，并通过回调打开家具设置。
- `PlannerPage` 管理两个独立弹窗的打开状态并传递现有家具业务回调。

## 验证

- 组件测试覆盖顶部问号入口、家具栏展开/收起、收起不触发家具选择变化，以及家具设置入口。
- 运行项目全量测试和构建检查。
- 不进行页面验收，由用户自行体验测试。
